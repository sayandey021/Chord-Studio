# Chord Studio

**Modern, Hardware-Accelerated Guitar Tablature, Chords & AI Audio Studio**

Chord Studio is an open source cross-platform music tablature viewer, chord progression analyzer, chromatic instrument tuner, and on-device AI transcription suite.

## Features

- **Precision Tablature & Interactive Chords**: Syntax-colored chord anchors, instant transposition, and smart auto-scroll.
- **Interactive Chord Inspector**: Tap any chord to see Guitar Fretboard & 61-Key Piano fingerings across all variations.
- **AI Audio & Lyrics Studio**: Neural network chord recognition (ONNX Runtime) and synchronized lyrics transcription (Whisper AI).
- **Chromatic Tuner**: Sub-cent real-time pitch detection for Guitar, Bass, Ukulele, and alternative tunings.
- **PDF Exporter**: Clean printable A4 chord sheets with Chord Studio branding and automated pagination.
- **Offline Library**: Fast SQLite database for offline favorites, custom playlists, and viewing history.
